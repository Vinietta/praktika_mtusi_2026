# Диагностика болезней растений

Мини-приложение для диагностики состояния растений по фотографии листа на основе модели EfficientNet-B0. Разработано в рамках учебной практики по компьютерному зрению (МТУСИ, 2026).

## Возможности
- Классификация 38 классов болезней растений (14 культур)
- Вывод уверенности модели и топ-3 предсказаний
- Сохранение истории проверок в JSON
- Экспорт результатов в CSV

## Структура репозитория

| Файл | Описание |
|---|---|
| `app.py` | Демонстрационное приложение на Streamlit |
| `classes.json` | Список классов модели (38 классов) |
| `best_efficientnet_b0.pth` | Веса обученной модели EfficientNet-B0 |
| `training_results.csv` | Результаты сравнения 5 архитектур |
| `practic.ipynb` | Jupyter-ноутбук с полным циклом обучения |
| `history.json` | Пример истории проверок |
| `diagnosis_report_*.csv` | Пример экспорта результатов |
